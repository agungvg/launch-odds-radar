Pre-token protocols ranked by expected value — terminal value × launch odds

How the price is made

implied value = K · TVL0.8 · growth · age · breadth · launch odds

  • Terminal value — K · TVL0.8. Value grows slower than TVL: a protocol ten times bigger is worth about six times more, not ten. K is anchored to this snapshot itself — the median tokenised market cap over the median tokenised TVL0.8 — so no number is imported from outside and no single outlier sets the price.
  • Growth — the 7-day TVL move, damped to ±20% and compounded over eight weeks, clamped to 0.5–2.0.
  • Age — how long the protocol has run with no token, on a log scale: older means more overdue. Missing listing date counts as neutral.
  • Breadth — 1 + 0.15 · log2(chains), capped at 1.8: each extra chain adds reach.
  • Launch odds — the share of protocols in the same category that already have a token, shrunk toward the snapshot-wide rate (prior weight 5). A big protocol in a category that almost never tokenises ranks below a smaller one in a category that usually does.

Nothing is priced by name: one function scores every protocol from the snapshot's own ten fields. “Records no token” means DefiLlama records none — a protocol on this board may still have a token its record does not carry. Implied values are this radar's claim, not a prediction of if or when a token is issued.
