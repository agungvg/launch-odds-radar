How the price is made

implied value = TVL · peer multiple · size factor · growth · age · breadth

  • Peer multiple — the category's median market-cap-per-TVL among tokens that already trade, winsorized at 5 and shrunk toward the snapshot-wide median (weight 8).
  • Size factor — a fitted log-log curve: bigger protocols carry a lower multiple. Fitted on the snapshot's own traded tokens, not assumed.
  • Growth — the 7-day TVL move, damped to ±35% of its size and never compounded: one week is noise, not a trend.
  • Age — how long the protocol has run with no token, on a log scale: older means more overdue. Missing listing date counts as one year.
  • Breadth — 1 + 0.02 per extra chain, at most +10%.
  • Launch odds — the share of protocols in the same category that already have a token, shrunk toward the snapshot-wide rate. Odds do not shrink the value: they set the expected value and the farm verdict.

Nothing is priced by name: one function scores every protocol from the snapshot's own ten fields. “Records no token” means DefiLlama records none — a protocol on this board may still have a token its record does not carry. Implied values are this radar's claim, not a prediction of if or when a token is issued. Farm plans are this radar's own suggestions, not financial advice.
